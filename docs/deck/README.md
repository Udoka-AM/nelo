# Pitch deck

`index.html` is the deck. It is a single self-contained file — open it in any
browser, no build and no server needed.

## Presenting

| Key | Action |
|-----|--------|
| `→` `Space` `Enter` | Next slide |
| `←` | Previous slide |
| `Home` / `End` | First / last slide |
| `O` | Overview grid — jump to any slide |
| `F` | Fullscreen |

Swipe left and right works on a touchscreen. Deep-link a slide with `#7`.

## Before you present

Slides marked with a dashed orange border are placeholders. Fill them in once the
build is done:

- **Team** — names and roles on the title slide and the closing slide
- **What actually ran** — what shipped, what was tested, and every stub, named

The scorecard is Stickiness & PMF, User Experience, Innovation and Presentation at
25% each. Half the score is UX and presentation, so the deck and the 3-minute video
are not the tidy-up at the end — they are half the marks.
